Módulo 06 — Coleções: Vetores

O que é um Vetor?

O vetor é uma estrutura de dados indexada, que pode armazenar uma determinada quantidade de valores do mesmo tipo sob um único nome. Dentro de um vetor, cada valor é identificado por um índice, que indica a posição do valor dentro do vetor, e em C essa contagem começa em zero.

Quando usar um Vetor?

Use um vetor quando precisar armazenar uma coleção de valores semelhantes, como notas, temperaturas ou resultados de leituras com um limite de tamanho já definido. Em C, o tamanho do vetor é definido na declaração e não pode ser alterado durante a execução do programa.

Percorrendo os índices e posições de um vetor

Vetores e For andam lado a lado, o contador i do for funciona como um índice para o vetor. A cada repetição, ele aponta para a posição seguinte, tornando possivel preencher ou acessar todos os elementos do vetor em sequência

Em um vetor int vet [5], existem cinco posições: vet[0], vet[1], vet[2], vet[3] e vet[4]. Para preencher o vetor, podemos usar um for percorrendo essas posições, atribuindo o valor de i ao índice correspondente do vetor, como no exemplo abaixo:

Exemplo e Resultado

Preenchendo um vetor


                    
#include 
#include 
int main()
{
    int vet [5];

    for (int i = 0; i < 5; i++){
    vet[i] = i * i;
    }
    //For é usado para preencher o vetor

    for (int i = 0; i < 5; i++){
    printf("%d", vet[i]);
    }
    
    //Outro for é usado para acessar todo o contéudo do vetor e exibi-lo
    
    return 0;
}

Resultado esperado:


                    014916

Entendendo o exemplo

Primeiro o vetor tem seu tipo e número de posições declaradas, antes de ser usado dentro do for. Depois é construido um for que tem como condição iniciar de 0 e ir no máximo até 4. Ao declarar o vetor dentro do for, utiliza-se o i já declarado na construção do for.

Na execução, o valor de i será igual a 0, e o primeiro índice do vetor também será de 0. Assim, após o valor de i ser incrementado pelo i++ o índice do vetor será incrementado junto, e graças a isso, o vetor será preenchido sequencialmente

A mesma regra serve para o segundo for, mas dessa vez o for irá servir para acessar o que está dentro do índice do vetor e exibirá na tela.

Exemplo sem o for

Preenchendo um vetor manualmente


                    
#include 
#include 
int main()
{
    int vet [5] = {0, 1, 4, 9, 16};
        
    printf("%d", vet[0]);
    printf("%d", vet[1]);
    printf("%d", vet[2]);
    printf("%d", vet[3]);
    printf("%d", vet[4]);
    
    return 0;
}

Resultado esperado:


014916

Entendendo o exemplo

O resultado é o mesmo do exemplo anterior, mas dessa vez o vetor foi preenchido manualmente. Cada posição do vetor foi preenchida com um valor específico, e depois cada posição foi usada individualmente para exibir o valor na tela.

Erros comuns

  • Percorrer mais posições que as declaradas dentro do vetor.
  • Esquecer de declarar o índice de um vetor
  • Tentar armazenar tipos diferentes dentro de um mesmo vetor
  • Criar um for com i tendo 1 como valor inicial, deixando de percorrer a posição 0
  • Não levar em conta que um vetor sempre começa do índice 0

Resumo

Vetores organizam coleções do mesmo tipo em sequência. Sempre começam em 0 e vão até um tamanho definido pelo programador. São acessados por índices, que são números inteiros que indicam a posição do elemento dentro do vetor. E são percorridos com estruturas de repetição, como o for, que permite acessar cada elemento do vetor em sequência.
