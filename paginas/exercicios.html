Exercício 1 — Classificação do jogador

Pelas regras do jogo, quem faz 100 pontos ou mais avança. De 60 a 99 pontos, recebe uma segunda chance. Abaixo de 60, precisa tentar novamente. 

int pontos = 100;

if (pontos >= 60) {
    printf("Segunda chance\n");
} else if (pontos >= 100) {
    printf("Avançou\n");
} else {
    printf("Tente novamente\n");
}
Com 100 pontos, o que esse código exibe?

Explicação da resposta

Com 100 pontos, a primeira condição, pontos >= 60, é verdadeira. O programa exibe Segunda chance e sai da estrutura condicional.

Para aplicar a regra do jogo, teste primeiro pontos >= 100 e depois pontos >= 60.

Exercício 2 — Pontuação acumulada

O jogador digita a pontuação de cada rodada. O valor -1 encerra a entrada. Considere que ele digita 12, 0, 7 e -1, nessa ordem. 

int pontos;
int total = 0;

scanf("%d", &pontos);

while (pontos != -1) {
    total += pontos;
    scanf("%d", &pontos);
}

printf("Total: %d\n", total);
Qual total será exibido?

Explicação da resposta

O laço soma 12 + 0 + 7 e chega a 19. O zero é uma pontuação válida e mantém o laço em execução. Ao ler -1, o programa encerra o laço antes da próxima soma.

int pontos[2][3] = {
    {10, 20, 30},
    {15, 25,  5}
};

int total = 0;

for (int rodada = 0; rodada < 3; rodada++) {
    /* Complete esta linha. */
}

printf("Total do segundo jogador: %d\n", total);
Qual instrução completa o laço corretamente?

Explicação da resposta

Em C, os índices começam em zero. A linha 1 corresponde ao segundo jogador. O laço mantém essa linha fixa e usa rodada para percorrer as três colunas. Com +=, o total acumula 15 + 25 + 5 e chega a 45 pontos.
