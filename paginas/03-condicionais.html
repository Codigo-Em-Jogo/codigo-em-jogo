Módulo 03 — Estruturas Condicionais

Estruturas Condicionais em C

Nem sempre um programa deve executar todas as instruções da mesma maneira. Em algumas situações, precisamos tomar decisões de acordo com determinadas condições.

As estruturas condicionais permitem que um programa escolha diferentes caminhos de execução, dependendo do resultado de uma condição.

Nesta aula, você aprenderá a utilizar as estruturas if e else, compreender os operadores relacionais e desenvolver programas que tomam decisões na linguagem C.

O que são estruturas condicionais?

As estruturas condicionais são recursos da programação que permitem executar diferentes instruções de acordo com uma condição.

Uma condição é uma expressão que pode ser avaliada como verdadeira ou falsa. Dependendo do resultado, o programa decide quais instruções serão executadas.

Imagine um sistema que verifica a idade de uma pessoa para determinar se ela é maior de idade. Se a idade for igual ou superior a 18 anos, o programa poderá apresentar uma mensagem informando que a pessoa é maior de idade.

Na linguagem C, utilizamos principalmente as estruturas if, else e else if para controlar essas decisões.

A estrutura if

A estrutura if é utilizada quando queremos executar uma ou mais instruções somente se uma determinada condição for verdadeira.

A palavra if significa "se" em inglês. Na programação, ela permite verificar uma condição antes de executar um bloco de comandos.

Sintaxe do if

if (condicao) {
    // Comandos executados se a condição for verdadeira
}

A condição deve ser escrita entre parênteses. Quando seu resultado é verdadeiro, o programa executa os comandos que estão entre as chaves. Caso seja falsa, esse bloco é ignorado.

A estrutura if...else

A estrutura if...else é utilizada quando precisamos escolher entre dois caminhos diferentes, de acordo com o resultado de uma condição.

Se a condição for verdadeira, o programa executa os comandos do bloco if. Caso seja falsa, executa os comandos do bloco else.

Sintaxe do if...else

if (condicao) {
    // Comandos executados se a condição for verdadeira
} else {
    // Comandos executados se a condição for falsa
}

Diferentemente do if utilizado sozinho, a estrutura if...else permite definir uma ação alternativa para quando a condição não for atendida.

Por exemplo, um programa pode verificar a idade de uma pessoa. Se ela tiver 18 anos ou mais, exibirá a mensagem "Maior de idade". Caso contrário, exibirá "Menor de idade".

A estrutura else if

A estrutura else if é utilizada quando precisamos verificar várias condições diferentes dentro de uma mesma decisão.

O programa avalia as condições na ordem em que aparecem. Quando encontra uma condição verdadeira, executa o bloco correspondente e ignora os demais blocos dessa sequência.

Sintaxe do else if

if (condicao1) {
    // Comandos da primeira condição
} else if (condicao2) {
    // Comandos da segunda condição
} else {
    // Comandos quando nenhuma condição anterior é verdadeira
}

Podemos utilizar quantos blocos else if forem necessários. O bloco else é opcional e representa a alternativa executada quando nenhuma das condições anteriores é verdadeira.

Por exemplo, um programa pode classificar a nota de um estudante. Se a nota for maior ou igual a 7, o estudante estará aprovado. Se for maior ou igual a 5, mas menor que 7, estará em recuperação. Caso contrário, estará reprovado.

Operadores relacionais

Os operadores relacionais são utilizados para comparar dois valores ou expressões. O resultado de uma comparação indica se a condição é verdadeira ou falsa.

Na linguagem C, os principais operadores relacionais são:

  • == Igual a
  • != Diferente de
  • > Maior que
  • < Menor que
  • >= Maior ou igual a
  • <= Menor ou igual a

Esses operadores permitem construir condições para que o programa tome decisões com base nos valores armazenados nas variáveis.

Exemplo de comparação

if (idade >= 18) {
    printf("Maior de idade");
}

Nesse exemplo, o operador maior ou igual a verifica se a idade é pelo menos 18. Se a comparação for verdadeira, a mensagem será exibida.

Operadores lógicos

Os operadores lógicos são utilizados quando precisamos combinar ou negar condições em uma estrutura condicional.

Na linguagem C, os principais operadores lógicos são:

  • && (E): retorna verdadeiro somente quando as duas condições são verdadeiras.
  • || (OU): retorna verdadeiro quando pelo menos uma das condições é verdadeira.
  • ! (NÃO): inverte o resultado lógico de uma condição.

Exemplo com o operador E

if (idade >= 18 && possuiDocumento == 1) {
    printf("Entrada permitida");
}

Nesse exemplo, a entrada será permitida somente se a pessoa tiver 18 anos ou mais e possuir documento, representado pelo valor 1 na variável possuiDocumento.

Exemplo com o operador OU

if (idade < 12 || idade >= 60) {
    printf("Desconto permitido");
}

Nesse caso, o desconto será permitido quando a pessoa tiver menos de 12 anos ou quando tiver 60 anos ou mais.

Exemplo com o operador NÃO

if (!(idade >= 18)) {
    printf("Menor de idade");
}

O operador ! inverte o resultado da comparação. Assim, a mensagem será exibida quando a idade for menor que 18 anos.

Exemplo prático: situação do estudante

Vamos desenvolver um programa que solicita a nota de um estudante e utiliza estruturas condicionais para verificar sua situação.

Se a nota for maior ou igual a 7, o estudante estará aprovado. Se estiver entre 5 e 7, estará em recuperação. Caso seja menor que 5, estará reprovado.

Código em C

#include <stdio.h>

int main() {
    float nota;

    printf("Digite a nota: ");
    scanf("%f", &nota);

    if (nota >= 7) {
        printf("Aprovado\n");
    } else if (nota >= 5) {
        printf("Recuperacao\n");
    } else {
        printf("Reprovado\n");
    }

    return 0;
}

Exemplo de execução

Digite a nota: 8
Aprovado

Erros comuns nas estruturas condicionais

Ao utilizar estruturas condicionais, alguns erros podem comprometer o funcionamento do programa. Conhecer esses erros ajuda a escrever códigos mais corretos e organizados.

Confundir = com ==

O operador = é utilizado para atribuir valores a uma variável, enquanto == é utilizado para comparar igualdade. 

if (idade == 18) {
    printf("Idade igual a 18");
}

Utilizar = no lugar de == pode alterar o valor da variável e produzir um resultado diferente do esperado.

Colocar ponto e vírgula após o if

Um ponto e vírgula colocado imediatamente após a condição encerra a instrução if, fazendo com que o bloco seguinte não dependa mais dessa condição. 

if (idade >= 18); {
    printf("Maior de idade");
}

No exemplo acima, a mensagem será exibida independentemente da idade, pois o bloco entre chaves não pertence ao if.

Organizar as condições na ordem incorreta

Em uma sequência de if e else if, a ordem das condições é importante, pois somente o primeiro bloco cuja condição seja verdadeira será executado.

Por isso, é necessário verificar cuidadosamente a lógica das comparações para evitar resultados incorretos.

Resumo da aula

Nesta aula, aprendemos que as estruturas condicionais permitem que um programa tome decisões de acordo com o resultado de determinadas condições.

Os principais conceitos estudados foram:

  • if: executa um bloco de comandos quando uma condição é verdadeira.
  • if...else: permite escolher entre dois caminhos diferentes.
  • else if: permite verificar várias condições em sequência.
  • Operadores relacionais: são utilizados para comparar valores, como ==, !=, >, <, >= e <=.
  • Operadores lógicos: permitem combinar ou negar condições, utilizando &&, || e !.

Também aprendemos que a ordem das condições influencia o resultado do programa e que pequenos erros, como confundir = com == ou acrescentar um ponto e vírgula após o if, podem comprometer seu funcionamento.

Com esses conhecimentos, você já consegue desenvolver programas simples que analisam informações e executam diferentes ações de acordo com as condições estabelecidas.
