Estrutura Repetitiva: While

Em muitos problemas, precisamos executar um mesmo conjunto de instruções várias vezes seguidas — por exemplo, ler vários valores digitados pelo usuário ou contar até um determinado limite.

Nesta aula, você vai aprender como funciona a estrutura repetitiva while, como controlar o início e o fim de um laço de repetição e como evitar o famoso loop infinito na linguagem C.

O que é uma estrutura de repetição?

Uma estrutura de repetição (também chamada de laço ou loop) permite que um bloco de código seja executado várias vezes enquanto uma condição permanecer verdadeira.

Sem uma estrutura de repetição, se quiséssemos exibir os números de 1 a 5 na tela, teríamos que escrever cinco comandos printf diferentes. Com o while, escrevemos a instrução uma única vez e definimos até quando ela deve se repetir.

Como funciona o while?

A palavra while significa "enquanto" em inglês. Antes de cada repetição, o programa avalia uma condição entre parênteses.

  • Se a condição for verdadeira, o programa executa os comandos dentro das chaves e, ao chegar no final do bloco, volta para testar a condição novamente.
  • Se a condição for falsa, o bloco é ignorado e o programa segue para as próximas instruções fora do while.

Sintaxe do while

while (condicao) {
                    // Comandos executados enquanto a condição for verdadeira
                }

Como o teste acontece no início, se a condição já começar falsa na primeira verificação, os comandos dentro do while não serão executados nenhuma vez.

Os três elementos de um laço com contador

Quando usamos o while para contar ou repetir uma tarefa um número determinado de vezes, organizamos o código em três etapas:

  1. Inicialização: criamos uma variável de controle (contador) antes do while com seu valor inicial, como int contador = 1;.
  2. Condição de parada: verificamos no while até onde essa variável pode ir, como while (contador <= 5).
  3. Atualização: alteramos o valor do contador dentro do bloco (por exemplo, contador++) para que a condição em algum momento se torne falsa.
Pense antes de continuar: e se esquecermos a atualização?

Se o valor de contador nunca mudar dentro do bloco, a condição contador <= 5 será sempre verdadeira. O programa ficará preso repetindo o código sem parar — situação conhecida como loop infinito.

Exemplo prático: contando de 1 a 5

Observe abaixo um programa em C que utiliza uma variável contador para exibir os números de 1 até 5 na tela.

Código em C

#include <stdio.h>

int main(void) {
    int contador = 1;

    while (contador <= 5) {
        printf("%d ", contador);
        contador++;
    }

    return 0;
}

Resultado esperado

1 2 3 4 5

Entendendo o programa passo a passo

  • A variável contador começa valendo 1.
  • O programa testa contador <= 5. Como 1 é menor ou igual a 5, exibe 1 e soma 1 ao contador (que passa a valer 2).
  • Esse processo se repete para os valores 2, 3, 4 e 5.
  • Quando contador chega a 6, a condição 6 <= 5 torna-se falsa e o laço é encerrado.

Quando não sabemos quantas vezes repetir

A grande vantagem do while é funcionar muito bem quando a repetição depende de um valor digitado pelo usuário — por exemplo, somar números até que o usuário digite 0 para encerrar.

Código em C

#include <stdio.h>
int main(void) {
    int numero;
    int soma = 0;

    printf("Digite um numero (0 para sair): ");
    scanf("%d", &numero);

    while (numero != 0) {
        soma = soma + numero;

        printf("Digite outro numero (0 para sair): ");
        scanf("%d", &numero);
    }

    printf("Soma total: %d\n", soma);

    return 0;
}

Exemplo de execução

Digite um numero (0 para sair): 4
Digite outro numero (0 para sair): 6
Digite outro numero (0 para sair): 5
Digite outro numero (0 para sair): 0
Soma total: 15

Erros comuns com o while

  • Esquecer de atualizar a variável de controle: faz com que a condição nunca mude e gere um loop infinito.
  • Colocar ponto e vírgula após o while: escrever while (contador <= 5); cria um laço vazio que trava o programa antes de executar o bloco entre chaves.
  • Não inicializar a variável antes do teste: testar uma variável sem valor inicial pode fazer o programa ler lixo de memória e se comportar de forma imprevisível.
  • Usar uma condição que já começa falsa: por exemplo, iniciar int x = 10; e testar while (x < 5) faz o bloco nunca ser executado.

Resumo

A estrutura while repete um bloco de instruções enquanto uma condição for verdadeira, testando essa condição antes de cada volta.

Ela é ideal tanto para contagens simples quanto para situações em que não sabemos previamente quantas repetições serão necessárias, como na leitura de dados até que o usuário digite um valor de parada.
