Módulo 02 — Estrutura Sequencial

Estrutura Sequencial em C

A estrutura sequencial é uma das formas mais básicas de organizar um programa. Nela, as instruções são executadas uma após a outra, seguindo a ordem em que foram escritas.

Nesta aula, você aprenderá a declarar variáveis, trabalhar com tipos de dados, receber informações do usuário, realizar cálculos e apresentar resultados utilizando a linguagem C.

O que é uma estrutura sequencial?

Na estrutura sequencial, o programa executa os comandos na ordem em que aparecem, de cima para baixo, sem utilizar estruturas de decisão ou repetição.

Por exemplo, podemos criar um programa que solicita dois números, realiza uma soma e apresenta o resultado na tela.

Para isso, seguimos três etapas: entrada de dados, processamento e saída de informações.

Variáveis e tipos de dados

Uma variável é um espaço na memória do computador utilizado para armazenar informações que podem ser utilizadas ou modificadas durante a execução de um programa.

Na linguagem C, precisamos informar o tipo de dado que cada variável irá armazenar antes de utilizá-la. Esse processo é chamado de declaração de variável.

Principais tipos de dados

  • int: armazena números inteiros, como 10, 25 e -3.
  • float: armazena números reais com casas decimais, como 7.5 e 3.14.
  • double: também armazena números reais, geralmente com maior precisão que float.
  • char: armazena um caractere, como 'A', 'B' ou '7'.

Como declarar uma variável?

Para declarar uma variável, escrevemos primeiro o tipo de dado e depois o nome que desejamos atribuir a ela. 

int idade = 18;
float altura = 1.75;
double preco = 29.90;
char letra = 'A';

Nesse exemplo, criamos quatro variáveis. Cada uma possui um tipo de dado e um valor inicial correspondente.

Observe que, na linguagem C, utilizamos o ponto para representar valores decimais e o ponto e vírgula para finalizar as instruções.

Entrada e saída de dados

Na linguagem C, podemos utilizar comandos para apresentar informações na tela e receber dados digitados pelo usuário.

Para isso, utilizamos principalmente as funções printf e scanf, disponíveis na biblioteca stdio.h.

Saída de dados com printf

A função printf permite exibir mensagens e valores na tela. 

#include <stdio.h>

int main(void) {
    int idade = 18;

    printf("Minha idade e: %d\n", idade);

    return 0;
}

Nesse exemplo, %d indica que será exibido um número inteiro. Já \n representa uma quebra de linha.

Entrada de dados com scanf

A função scanf permite receber informações digitadas pelo usuário e armazená-las em variáveis. 

#include <stdio.h>

int main(void) {
    int idade;

    printf("Digite sua idade: ");
    scanf("%d", &idade);

    printf("Idade informada: %d\n", idade);

    return 0;
}

Nesse exemplo, o programa solicita a idade do usuário e armazena o valor digitado na variável idade.

O símbolo & utilizado em scanf permite informar o endereço de memória da variável que receberá o valor digitado.

Formatadores mais utilizados

  • %d: utilizado para números inteiros.
  • %f: utilizado para números decimais do tipo float em printf e scanf.
  • %lf: utilizado para ler valores double com scanf.
  • %c: utilizado para caracteres.

Operadores aritméticos

Os operadores aritméticos permitem realizar cálculos matemáticos utilizando valores e variáveis em um programa.

Na linguagem C, os principais operadores são:

  • + : adição.
  • - : subtração.
  • * : multiplicação.
  • / : divisão.
  • % : resto da divisão inteira.

Exemplo de operação matemática

int numero1 = 10;
int numero2 = 5;
int soma;

soma = numero1 + numero2;

Nesse exemplo, as variáveis numero1 e numero2 armazenam os valores 10 e 5. O operador de adição realiza a soma, e o resultado 15 é armazenado na variável soma.

É importante lembrar que, quando dividimos dois valores inteiros em C, o resultado também é inteiro, com a parte decimal descartada.

Exemplo prático: área de um retângulo

Vamos desenvolver um programa que solicita a base e a altura de um retângulo, calcula sua área e apresenta o resultado na tela.

Código em C

#include <stdio.h>

int main(void) {
    float base, altura, area;

    printf("Digite a base: ");
    scanf("%f", &base);

    printf("Digite a altura: ");
    scanf("%f", &altura);

    area = base * altura;

    printf("Area: %.2f\n", area);

    return 0;
}

Exemplo de execução

Digite a base: 5
Digite a altura: 3
Area: 15.00

Entendendo o programa

Primeiro, declaramos três variáveis do tipo float: base, altura e area.

Depois, utilizamos scanf para receber os valores informados pelo usuário.

Em seguida, multiplicamos a base pela altura e armazenamos o resultado na variável area.

Por fim, utilizamos printf para apresentar o resultado. O formato %.2f exibe o número com duas casas decimais.

Erros comuns

Ao desenvolver programas em C, alguns erros são frequentes entre os iniciantes.

  • Esquecer o ponto e vírgula ao final das instruções.
  • Utilizar uma variável sem declará-la.
  • Utilizar o especificador de formato incorreto em printf ou scanf.
  • Esquecer o símbolo & no scanf ao ler variáveis numéricas comuns.
  • Confundir atribuição (=) com comparação (==).
  • Esperar um resultado decimal ao dividir dois números inteiros.

Resumo

A estrutura sequencial executa as instruções na ordem em que foram escritas.

Nesta aula, aprendemos sobre variáveis, tipos de dados, operadores aritméticos, entrada e saída de informações com printf e scanf.

Também desenvolvemos um programa para calcular a área de um retângulo, utilizando entrada, processamento e saída.

Esses conhecimentos serão importantes para estudar as estruturas condicionais na próxima aula.
