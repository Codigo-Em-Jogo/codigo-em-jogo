# Código em Jogo

Aprenda lógica de programação de forma prática e progressiva.

---

## Sobre o projeto

**Código em Jogo** é uma plataforma de aprendizagem progressiva voltada para estudantes que estão tendo seu primeiro contato com lógica de programação e linguagem C. O conteúdo foi organizado em uma trilha de sete módulos, indo de conceitos básicos de algoritmos até estruturas de dados como vetores e matrizes.

O projeto foi desenvolvido como Projeto Integrador do 1º semestre do curso de Desenvolvimento de Sistemas Multiplataforma da Fatec Marília, no 2º semestre letivo de 2026.

A definição do conteúdo foi orientada por um levantamento diagnóstico realizado em outubro de 2026 com 37 estudantes do curso de DSM da Fatec Marília, do 1º ao 6º semestre. O questionário buscou entender as principais dificuldades no aprendizado de lógica de programação, os conteúdos que mais precisam de apoio e as formas de apresentação consideradas mais úteis. Os resultados orientaram a organização da trilha, a escolha dos exemplos comentados e a estrutura dos exercícios.

---

## Funcionalidades

- Conteúdo organizado em sete módulos progressivos
- Exemplos de código em C comentados
- Exercícios para fixação do conteúdo
- Respostas para consulta e conferência
- Navegação entre os módulos de aprendizagem

---

## Conteúdo programático

1. Algoritmos e primeiros passos
2. Estrutura sequencial
3. Estruturas condicionais
4. Repetição com while
5. Repetição com for
6. Vetores
7. Matrizes
